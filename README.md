# Real-time Canvas

เว็บไวท์บอร์ดสำหรับวาดรูปและพูดคุยแบบเรียลไทม์ โดยใช้ React, TypeScript และ Socket.io

## ฟีเจอร์ปัจจุบัน

- วาดรูปพร้อมกันแบบเรียลไทม์
- เลือกสีและขนาดเส้นได้
- โหมดปากกาและยางลบ
- ล้างกระดานพร้อมกันทุกคน
- ต้องได้รับการยืนยันจากผู้ใช้ทุกคนก่อนล้างกระดาน
- ดาวน์โหลดภาพกระดานเป็นไฟล์ PNG
- แสดงจำนวนผู้ใช้งานออนไลน์
- ห้องแชตแบบเรียลไทม์
- กรอกชื่อผู้ใช้ก่อนเข้าห้อง
- สร้างห้องใหม่หรือเข้าร่วมห้องเดิม
- ระบบสร้าง Room ID อัตโนมัติเมื่อสร้างห้องใหม่
- เครื่องมือเส้นตรง, สี่เหลี่ยม, วงกลม, ลูกศร และ Text แบบเรียลไทม์
- แสดงรายชื่อผู้ใช้ที่อยู่ในห้องปัจจุบัน
- ตั้งรหัสผ่านห้องแบบเลือกได้
- ลบห้องและรหัสผ่านอัตโนมัติเมื่อไม่มีผู้ใช้อยู่ในห้อง
- รองรับเมาส์, touch และ stylus ผ่าน Pointer Events
- Undo / Redo ภายในห้อง
- ยางลบแบบลบจริงด้วย Canvas compositing
- รองรับหน้าจอ Retina และบันทึกงานไว้ใน browser อัตโนมัติ
- แยกห้องวาดรูปด้วย query string เช่น `?room=team-a`
- แสดง Room ID ปัจจุบันและคัดลอกลิงก์ห้องเพื่อแชร์ได้
- เปิด Invite Link แล้วกรอกชื่อและยืนยัน Room ID ก่อนเข้าห้อง

- Node.js 18 ขึ้นไป
- npm

## วิธีติดตั้งและรัน

เปิด Terminal สองหน้าต่าง แล้วรันคำสั่งดังนี้

### 1. ติดตั้งและรัน Backend

```bash
cd backend
npm install
npm run dev
```

เซิร์ฟเวอร์จะทำงานที่ `http://localhost:3001`

### 2. ติดตั้งและรัน Frontend

```bash
cd frontend
npm install
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดงใน Terminal โดยปกติคือ `http://localhost:5173`

ระบบจะให้กรอกชื่อผู้ใช้, Room ID และรหัสผ่านที่หน้าเริ่มต้น โดยเลือกได้ว่าจะสร้างห้องใหม่หรือเข้าร่วมห้องเดิม

นอกจากนี้ยังสามารถเปิด Invite Link รูปแบบนี้ได้ ระบบจะนำ Room ID ไปกรอกไว้ล่วงหน้า แล้วให้ผู้รับกรอกชื่อและยืนยันการเข้าห้อง:

```text
http://localhost:5173/?room=team-a
```

## วิธีใช้งาน

- เลือกโหมด **ปากกา** เพื่อวาด และ **ยางลบ** เพื่อลบส่วนที่วาด
- ใช้แถบสีเพื่อเลือกสี และแถบขนาดเพื่อปรับความหนาของเส้น
- ใช้ **Undo** หรือ **Redo** เพื่อย้อนกลับหรือทำซ้ำการแก้ไข
- การ Undo / Redo จะส่งผลเฉพาะ operation ของผู้ใช้คนนั้น และซิงก์ให้ผู้ใช้ในห้องเห็นตรงกัน
- เลือกเครื่องมือรูปทรงเพื่อวาดเส้นตรง, สี่เหลี่ยม, วงกลม, ลูกศร หรือวางข้อความ
- กด **บันทึกภาพ** เพื่อดาวน์โหลดกระดานเป็น PNG
- กด **ล้างกระดาน** เพื่อล้างภาพของทุกคนในห้อง
- การล้างกระดานจะสำเร็จเมื่อผู้ใช้ทุกคนกดยืนยัน หากมีคนกดยกเลิก คำขอจะถูกยกเลิก
- พิมพ์ข้อความใน Live Chat เพื่อคุยกับผู้ใช้ในห้องเดียวกัน
- กด **ออกจากห้อง** เพื่อออกจากห้องปัจจุบันและกลับไปหน้าเลือกห้อง
- ดู Room ID ที่ส่วนหัว และกด **คัดลอกลิงก์** เพื่อส่งลิงก์ให้ผู้ใช้อื่น
- ดูรายชื่อผู้ใช้งานปัจจุบันได้จากแถบสมาชิกใน Live Chat

### การสร้างและเข้าห้อง

- เลือก **สร้างห้อง** แล้วระบบจะสร้าง Room ID ให้โดยอัตโนมัติ
- คัดลอก Room ID หรือลิงก์ห้องเพื่อแชร์ให้ผู้ใช้อื่น
- ใส่รหัสผ่านถ้าต้องการให้เป็นห้องส่วนตัว หรือเว้นว่างเพื่อสร้างห้องสาธารณะ
- ถ้าเลือก **เข้าร่วมห้อง** ต้องใช้ Room ID ที่มีอยู่แล้ว
- ห้องที่มีรหัสผ่านต้องกรอกรหัสผ่านให้ตรงกัน
- ผู้ใช้ที่อยู่ใน Room ID เดียวกันจะเห็นกระดานและแชตร่วมกัน

```text
http://localhost:5173/?room=design-team
```

ถ้าไม่ระบุ room ใน URL ระบบจะให้ผู้ใช้กรอก Room ID เอง ส่วนห้อง `main` เป็นห้องเริ่มต้นของระบบ

## การทำงานโดยสรุป

1. ผู้ใช้วาดเส้นบน canvas
2. Frontend วาดเส้นทันทีบนหน้าจอของผู้ใช้
3. Frontend ส่งพิกัด สี และขนาดเส้นผ่าน Socket.io
4. Backend กระจายข้อมูลไปยังผู้ใช้คนอื่น
5. ผู้ใช้คนอื่นวาดเส้นเดียวกันบน canvas ของตัวเอง

การแชตและการล้างกระดานใช้หลักการกระจาย event แบบเดียวกัน

## การบันทึกข้อมูล

- ภาพของแต่ละห้องจะถูกบันทึกไว้ใน `localStorage` ของ Browser อัตโนมัติ
- ชื่อผู้ใช้, Room ID และรหัสผ่านจะถูกเก็บชั่วคราวใน `sessionStorage` เพื่อให้ Refresh แล้วยังกลับเข้าห้องเดิมได้
- Undo / Redo จะเก็บประวัติใน Browser สูงสุด 30 ขั้นตอน
- รายชื่อห้อง, รหัสผ่านห้อง และจำนวนผู้ใช้งานถูกเก็บไว้ในหน่วยความจำของ Backend
- ห้องที่ไม่มีผู้ใช้งานจะถูกลบออกจากหน่วยความจำอัตโนมัติ ยกเว้นห้อง `main`
- การรีสตาร์ต Backend จะล้างสถานะห้องและจำนวนผู้ใช้งาน แต่ข้อมูล local ของ Browser จะยังคงอยู่

## สิ่งที่ควรพัฒนาต่อ

- บันทึกประวัติการวาดถาวรบนฐานข้อมูลหรือ Object Storage
- ส่ง snapshot ล่าสุดจาก Backend ให้ผู้ใช้ที่เพิ่งเข้าห้อง
- เพิ่มระบบยืนยันตัวตนและจัดการบัญชีผู้ใช้
- เพิ่มสิทธิ์เจ้าของห้องและการเชิญสมาชิก
- เพิ่มการตรวจสอบข้อมูลและจำกัดขนาด payload บน Backend ให้ละเอียดขึ้น

## หมายเหตุ

โปรเจกต์นี้ใช้ `http://localhost:3001` สำหรับ Backend และ `http://localhost:5173` สำหรับ Frontend ในโหมดพัฒนา หากเปลี่ยน port หรือ deploy ขึ้น production ต้องแก้ค่า CORS และ URL ของ Socket.io ให้ตรงกับสภาพแวดล้อมใหม่

- เมื่อยืนยันครบ ระบบล้างกระดานและปิดหน้าต่างยืนยันของทุกคนทันที
